# 🛡️ Військовий Кібер-Аудит (Military Cyber Audit) для Android

**Версія:** 1.0.0  
**Призначення:** Автономний мобільний сканер для виявлення шпигунського ПЗ (RAT/Spyware), фантомних додатків знайомств, несанкціонованого фонового збору координат та перехоплення сесій на смартфонах особового складу.

---

## 🚀 Як встановити та використовувати бійцю

1. **Встановлення:**
   * Завантажте файл `MilitaryCyberAudit.apk` (через флешку, штатний кабель або з GitHub Actions).
   * Дозвольте встановлення та відкрийте додаток.
2. **Сканування в 1 клік:**
   * Натисніть велику кнопку **«Перевірити телефон»**.
   * Додаток за 3–5 секунд перевірить усі встановлені програми та системні права.
3. **Результат:**
   * 🟢 **БЕЗПЕЧНО:** Жодних небезпечних шпигунських дозволів не виявлено.
   * 🔴 **ЗНАЙДЕНО ЗАГРОЗИ:** Відображається список підозрілих програм з червоною кнопкою **«Видалити»**.
4. **Штабні перевірки:**
   * Натисніть кнопку **«Перевірити Telegram»** ➔ відкриється екран активних сесій месенджера. Переконайтеся, що немає чужих пристроїв.
   * Натисніть кнопку **«Вимкнути GPS у Камері»** ➔ вимкніть збереження геоданих у фотографіях.
   * Натисніть **«Скопіювати звіт для командира»** ➔ готовий текст для службового звіту підрозділу.

---

## 🔍 Що саме перевіряє додаток

* **🚨 Служби доступності (`Accessibility Services`):** головний маркер вірусів, що читають екран, повідомлення та перехоплюють клавіатуру.
* **📍 Фонова геолокація (`ACCESS_BACKGROUND_LOCATION`):** виявлення програм, які знімають координати при вимкненому екрані для наведення ударів.
* **📦 Sideloaded програми:** виявлення додатків, встановлених не з офіційного Google Play (скинутих через чати, сайти знайомств або браузер).
* **🎙️ Доступ до мікрофону, камери та SMS:** контроль програм, які можуть приховано записувати розмови або перехоплювати коди підтвердження.
* **⚡ Цілісність системи:** наявність Root-прав (Magisk/SuperSU) та увімкненого налагодження по USB.

## ⚙️ Як скомпілювати APK

### Варіант А: Автоматично через GitHub Actions (Без встановлення програм на ПК)
1. Зробіть `git push` змін у репозиторій.
2. Перейдіть на GitHub у вкладку **Actions** ➔ **«Збірка MilitaryCyberAudit APK»** ➔ натисніть **Run workflow**.
3. За 2 хвилини хмара GitHub збере свіжий підписаний файл `MilitaryCyberAudit.apk` у розділі **Artifacts**, готовий до завантаження.

### Варіант Б: Локально через Android Studio
1. Відкрийте папку `android_app` в Android Studio.
2. Дочекайтеся синхронізації Gradle.
3. Виберіть меню **Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)**.
