# Rules

- **Do not modify files or execute modifications immediately on a user request.** When a request is made, first explain your proposed approach, describe the changes you can make (or provide examples/alternatives), and wait for the user's explicit command/approval to proceed before modifying any files or running commands.
- **Git Commits On Demand:** Do NOT automatically execute git commits after code changes. Execute `git add` and `git commit` ONLY when the user explicitly requests to commit (e.g. "закоміть", "комміть"). When requested, execute the commit immediately with a relevant Ukrainian commit message.
- **Mandatory Changelog & Version Sync (1 Commit = 1 Version):** During an active working session, accumulate code changes without bumping the version badge on every micro-edit. Consolidate all session changes into `CHANGELOG.md` and bump the UI version badge ONCE right before executing the user's explicit commit command ("закоміть").
- **No temporary scripts in workspace:** All temporary helper scripts, patch tools, and test scripts must be placed in the isolated artifact scratch directory or deleted immediately after execution to keep the workspace completely clean.
- **100% Offline-First Runtime:** Every HTML application must work as a standalone file without internet access; local libraries from `v8/` (`tailwind.js`, `lucide.js`, `xlsx.js`, `docx.js`, `jszip.min.js`) take priority with safe fallbacks.
- **Rock-Solid Layouts & Popovers on Zoom:** Toolbars with filters and counters must be organized in stable multi-row layouts (Row 1: filters & search; Row 2: full-width summary stats & actions) to prevent layout shifts at high browser zoom levels (125–175%). Dropdowns and popovers in the right half of the screen must ALWAYS use `right-0` (expanding inwards) to prevent horizontal viewport clipping. Modal windows must have a high stacking context (`z-[200]` / `z-[210]`).
- **HUB & Interactive Version Badge Sync:** Every application in the suite must have a clickable/interactive version badge (e.g. `v3.4.0`, using clean SVG icons instead of emoji) in its header that opens an in-app Changelog modal. When updating an application, its corresponding card in **HUB (`index.html`)** must be kept 100% in sync with version, release date, and tags.
- **Modern UI Baseline (`impeccable` + `modern-web-guidance`):** All UI crafting, redesigns, typography, color systems, spacing, component polish, and UX decisions are governed strictly by **`impeccable`** (in **Operate** mode for dense, scanable tools without nested cards, decorative glassmorphism/blur, or emoji-icons) together with **`modern-web-guidance`** for up-to-date HTML/CSS APIs. Require full Ukrainian Cyrillic support and `tabular-nums` in numeric tables; avoid cliché AI font/palette defaults unless an explicit brief specifies otherwise. The offline and zoom-stability constraints above remain mandatory.
