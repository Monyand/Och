# Стандарти військової нормалізації та парсингу (Tactical Parsing)

При розробці парсерів, аналізаторів тексту та обробників військових зведень у цьому проєкті обов'язково дотримуватися наступних стандартів:

---

## 1. Військова нормалізація тексту (`normalizeMilitaryText`)
Військові донесення часто містять суміш кирилиці та латиниці через різні розкладки клавіатури, нерозривні пробіли з месенджерів та спецсимволи.
- **Омогліфи:** Замінювати візуально однакові латинські літери на кириличні в україномовних назвах (наприклад, `C` -> `С`, `A` -> `А`, `P` -> `Р`, `O` -> `О`, `X` -> `Х`, `E` -> `Е`, `T` -> `Т`, `K` -> `К`, `H` -> `Н`, `B` -> `В`, `M` -> `М`).
- **Пробіли:** Замінювати нерозривні пробіли (`\u00A0`), табуляції та багаторазові пробіли на один стандартний пробіл.
- **Апострофи:** Уніфікувати всі види апострофів (`'`, `'`, `ʼ`, `"`) до єдиного стандарту `'`.

```javascript
function normalizeMilitaryText(str) {
    if (!str) return '';
    return str
        .replace(/[\u00A0\u1680\u180e\u2000-\u200b\u202f\u205f\u3000\ufeff]/g, ' ')
        .replace(/[\u2018\u2019\u02bc\u0060\u00b4]/g, "'")
        .replace(/\s+/g, ' ')
        .trim();
}
```

## 2. Розумний захист дат (`parseSafeDate`)
Оператори часто випадково вказують зайву цифру перед 4-значним роком (наприклад, `62026-08-25` замість `2026-08-25`) або вставляють крапки замість дефісів.
- Використовувати регулярний вираз очищення року: `dateStr.replace(/^[0-9]+(?=(?:19|20)\d{2})/, '')`.
- Завжди перевіряти дату на валідність `isNaN(Date.parse(date))` та використовувати надійний фолбек (наприклад, на дату створення запису).

```javascript
function parseSafeDate(rawDateStr, fallbackDateStr = '') {
    if (!rawDateStr) return fallbackDateStr;
    let clean = String(rawDateStr).trim();
    // Очищення випадкових цифр перед роком 20XX або 19XX
    clean = clean.replace(/^[0-9]+(?=(?:19|20)\d{2})/, '');
    if (isNaN(Date.parse(clean))) {
        return fallbackDateStr;
    }
    return clean;
}
```

## 3. Безпечний парсинг списків (Захист калібрів)
- **Заборонено:** використовувати агресивне очищення на кшталт `^[-•*\s\d.)]+`, оскільки воно зрізає початкові цифри калібрів (`1. 5.45х39 магазин` перетвориться на `магазин`).
- **Обов'язковий шаблон очищення маркерів списку:**
```javascript
// Зрізає лише справжні номери (1., 1), a., a), -) і зберігає 5.45 / 7.62 / 12 кал
let cleanText = text.replace(/^\s*(?:(?:\d+|[a-zA-Zа-яА-ЯіїєґІЇЄҐ])[\.\)]\s*|[-•*–—+]\s*)+/, '').trim();
```

## 4. Каталог військових одиниць виміру
При парсингу майна, БК та спорядження завжди підтримувати стандартизовані категорії та відмінки:
- **Штучний облік:** `шт.` (синоніми: `шт`, `щт`, `т`).
- **Комплекти:** `к-кт` (синоніми: `к-кт`, `к-т`, `комплект`, `комплекти`, `компл`).
- **Пари:** `пара` (1), `пари` (2-4), `пар` (5+).
- **Одиниці:** `од.`
- **Довжина:** `м`, `пог. м` (`пог.м`, `пог м`, `метри`).
- **Будівельні/інженерні одиниці:** `рул.` (`рулон/рулонів`), `бухта` / `бухти` / `бухт`.
- **Фасування:** `уп.` (`упаковка`), `ящ.` (`ящик`), `бан.` (`банка`), `пляш.` (`пляшка`), `кан.` (`каністра`).
- **Об'єм/вага:** `л` (`літр`), `кг` (`кілограм`).

## 5. Одиничний облік одноразових засобів (`implicitConfigs`)
Для одноразових гранатометів, вогнеметів та ручних гранат (`РПГ-18`, `РПГ-22`, `РПГ-26`, `РПГ-75М`, `РПГ-76`, `M67`, `Ф-1`, `РГД-5`, `РГН`, `РГО` тощо) — якщо в тексті є лише згадка типу зброї без явної кількості (наприклад, `Витрачено РПГ-26`), система повинна автоматично зараховувати це як **1 шт**.
